최종 디자인은 `design/screens/`의 HTML 파일이다. 브라우저로 열면 실제 화면 크기(390×844)로 보인다. 앱 화면을 만들 때는 **그 파일의 색·크기·간격을 그대로 따르고**, 아래 규칙과 다르면 이 문서를 우선한다.

## 4. 모양 규칙 (가장 중요)

- **사진·옷 그림 칸·색 칩은 각진 네모(모서리 0).** 피드 사진은 화면 끝까지 붙이고 사진 사이는 2px.
- **누르는 것은 둥근 네모.**

| 요소 | 모서리 | 크기 |
|---|---|---|
| 큰 버튼 (다음·옷장에 넣기·완료) | 14 | 높이 54, 좌우 16 여백, 꽉 채움 |
| 카드 (결과 아이템·폴더 줄·목록) | 16 | 안쪽 여백 10~14 |
| 정보 막대 ("모든 저장에 담았어요"·"고른 것") | 14 | 높이 44~46 |
| 작은 흰 버튼 (폴더에 담기·바꾸기·보기·편집) | 9 | 높이 32 |
| 선택 막대 바깥 / 안쪽 (부위·핏 고르기) | 13 / 9 | 바깥 여백 4, 안쪽 높이 36 |
| 태그 (활용·비슷함·필요) | 7 | 높이 26 |
| 뒤로 버튼 | 13 | 40×40 (결과 화면 사진 위는 44×44) |
| 체크 표시 | 8 | 24~26 정사각 |
| 목록 속 작은 썸네일 | 8 | 40×48 등 |
| 아래에서 올라오는 시트 | 위쪽 20 | — |
| 진행 막대 | 끝 둥글게 | 높이 4 |

예외: 홈 피드 사진 위 저장 버튼은 지름 36 동그라미, 챗봇 말풍선은 모서리 20(꼬리 쪽 6)으로 동글동글하게.

## 5. 글라스 효과

반투명 흰 카드 = 흰색 55% + 흰 테두리 1px(90%) + 옅은 그림자 + 뒤 흐림.

- CSS 원본: `background: rgba(255,255,255,0.55); border: 1px solid rgba(255,255,255,0.9); box-shadow: 0 1px 2px rgba(46,26,92,0.05), 0 6px 20px rgba(46,26,92,0.07); backdrop-filter: blur(20px) saturate(160%)`
- React Native: `expo-blur`의 `BlurView`(intensity 30~40, tint "light")를 뒤에 깔고, 위에 `rgba(255,255,255,0.55)` 배경 + 흰 테두리 + 그림자. 바탕이 단색이라 흐림이 잘 안 보여도 괜찮다 — 반투명 흰색과 그림자가 핵심.
- 고른 상태: 흰색 100% 배경 + 그림자 `0 1px 4px rgba(46,26,92,0.14)` (선택 막대 안쪽), 또는 2px `#9B7BE0` 테두리 + 체크 표시 (카드).

## 8. 서버와 맞춘 것 / 아직 정할 것

- 갭 분석 결과의 화면 표현은 **활용 · 비슷함 · 필요**. 서버 값 `구매`는 화면에 '필요'로 보여 준다.
- 핏 **'모르겠어요'는 11/11 버전에서 뺀다** — 서버가 핏이 있는 종류는 핏을 꼭 받게 되어 있다. 넣을지는 팀이 다시 정한다.
- 저장 버튼은 하트가 아니라 북마크 모양이다. 서버 경로 이름은 아직 `/heart`다(바꿀지 팀이 정할 예정).
- 서버 주소·키는 `mobile/.env`에 `EXPO_PUBLIC_` 이름으로 넣고, `.env`는 올리지 않는다.

## 9. Claude Code에 붙여 넣을 요청 (목요일 분)

**① 앱 뼈대**

> `mobile/` 폴더에 Expo 앱을 새로 만들어 줘. create-expo-app 최신 버전, TypeScript, expo-router를 쓰고 기본 예제 화면은 지워 줘. `design/DESIGN.md` 6절대로 하단 탭 5개(홈·추천·챗봇·옷장·마이)와 아이콘을 만들고, 각 탭은 제목만 있는 빈 화면으로 둬. 글꼴은 Noto Sans KR, 바탕색은 #F4EFFC. 다 되면 내가 실행할 명령어를 알려 줘. 커밋은 하지 마.

**② 옷 추가 ①**

> `design/DESIGN.md` 규칙을 지켜서 `design/screens/20-add-item-1-kind.html`과 똑같이 생긴 '옷 추가 ①' 화면을 만들어 줘. 옷장 탭에 임시로 '+ 옷 추가' 버튼을 두고 누르면 열리게 해. 부위를 고르면 DESIGN.md 7절의 그 부위 종류만 보이고, 종류를 하나 고르면 '다음' 버튼이 켜져. 아직 서버 연결은 하지 마. 커밋은 하지 마.

**③ 옷 추가 ②**

> 이어서 `design/screens/21-add-item-2-color-fit.html`과 똑같은 '옷 추가 ②' 화면을 만들어 줘. 색은 DESIGN.md 7절 값으로, 데님 색은 데님팬츠·데님재킷일 때만 보여 줘. 핏은 고른 종류에 맞는 보기만 보이고, 핏이 없는 종류면 핏 칸을 숨겨. '모르겠어요'는 빼. '옷장에 넣기'를 누르면 지금은 앱 안 임시 목록에 저장하고 옷장 탭으로 돌아가게 해 줘. 커밋은 하지 마.
