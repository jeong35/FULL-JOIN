# B안: 옷 그림 통일 (11/22~)

옷 추가 시안 그림(`../source/icons.json`, 399개)의 긴소매를 지금 앱 그림(v12)의 '코트 팔'로 다시 그리고,
카라를 셔츠 카라 기준으로 맞추고, 핏별(슬림·오버사이즈) 그림을 같이 만든다.

## 다시 만들기 (FULL-JOIN 폴더에서)

```
cd design/add-item/sleeves
python3 sleeves_b.py 상의            # → ../source/icons_b.json · weaves_b.json, ../../kind-icons/fits_b.json, log.json
python3 sleeves_b.py 아우터          # 같은 파일에 더한다(묶음마다 따로 돌려도 된다)
python3 dresses_build.py             # 원피스·점프수트(상의 그림을 읽으므로 상의 다음에)
python3 motifs_build.py              # 노르딕 니트 · 레터링 결 → ../source/motifs_b.json(상의 다음에)
python3 crop_build.py                # 크롭 그림(셔츠·블라우스·후드·트레이닝 상의·카디건·후드집업·베스트·민소매, 핏별) → ../source/crop_b.json(상의 다음에)
python3 argyle_build.py              # 무늬 아가일(니트·카디건·베스트, 크롭 포함, 핏별) → ../source/argyle_b.json(crop_build 다음에)
python3 halfzip_build.py             # 하프넥 고침 · 하프집업 목 → ../source/halfzip_b.json(상의 다음에)
cd .. && python3 gen_add_item.py      # → mobile/src/data/wardrobeArt.ts, design/kind-icons/icons_v13.json
cd ../kind-icons && python3 gen_ts.py icons_v13.json ../../mobile/src/data/kindIcons.ts
```

필요한 것: Python 3, `shapely`, `svgpathtools` (확인 그림은 `playwright`).

## 파일

- `sleeves_b.py` — 소매 다시 그리기 + 핏별 그림. 묶음(`BATCHES`)마다 돌린다. '상의'·'아우터'(11/23).
  아우터: 재킷·트위드·레더·데님·점퍼·사파리·퍼코트·무스탕·숏/하프/롱코트·트렌치·숏/롱/경량패딩 + 퍼자켓(소매 구분선이 없어 핏만).
  코트 털 결(fur|숏코트·하프코트·롱코트)도 코트 기본 그림의 소매 옮기기로 같이 옮긴다. 무스탕 소매 끝 털처럼 윤곽 밖으로 나온 소매 선도 새 소매에 맞춘다.
- `collars.py` — 카라 다시 만들기(셔츠 카라 기준) + 하프넥·터틀넥 목 고치기(11/23).
- `outer_collars.py` — 퍼자켓 '후드'(옛 큰 칼라, 짧은 털)에 털 점 채우기(아우터 묶음에서 씀). 스탠드는 사진처럼 칼라를 몸판과 이어 목 밑 선 없이 앞만 V로 벌린 안(fur_stand_photo, 결정 전).
  코트·재킷 칼라는 그대로 두기로 함(11/23).
- `shirt_collar.py` — 셔츠 카라 다시 그림(뒷띠 + 날개, 11/23). sleeves_b.py 상의 묶음에서 collars.py 다음에 씀.
- `motifs_build.py` — 노르딕 니트(짜임 '노르딕 가로'·'노르딕 목둘레') · 프린팅('레터링'·'작은 로고') 결(11/23).
  다 그려진 핏별 기본 그림에서 목·어깨·몸판 자리를 재서 긋는다. 팔 무지 = 소매 재봉선 사이 몸판만.
- `argyle_build.py` — 무늬 아가일(11/27): 짜임 '아가일'(선만, 오버사이즈에서 꺾임)을 빼고 무늬 아가일 하나로. 핏별 몸판·소매 자리를 재서
  마름모를 새로 그린다. 무늬 모양 정석 · 큰 아가일 · 가슴 띠 · 세로 띠(카디건), 팔(팔까지 · 몸통만), 아가일 색은 앱이 칠한다.
- `crop_build.py` — 크롭 그림(11/27): 기장 '크롭'이 칩만 있던 상의도 그림이 바뀌게. 맨투맨 크롭처럼 몸판만 곧게 자르고(소매 재봉선 사이)
  소매는 그대로. 밑단 높이는 어깨 재봉선 꼭대기 → 밑단의 0.70(베스트는 어깨 꼭대기부터 0.74, 슬림은 레귤러와 같은 높이).
  밑단 시보리가 있던 옷은 크롭 밑단에도 긋고, 밑단에 걸린 주머니는 빼고 지퍼 · 여밈은 밑단까지. 민소매는 끈 크롭(i49) 높이 + 밑단 띠.
  블라우스 허리 끈은 밑단 조임으로(띠를 밑단 몸판 폭에 맞추고 끈 가닥은 짧게, "블라우스 크롭은 밑단에 맞추자").
  gen_add_item.py가 기장 '크롭' 보기 · 셔츠 · 블라우스 카라 × 기장 × 디테일 조합 · 슬리브리스 민소매|크롭에 달고, 베스트엔 기장 칸을 더한다.
- `halfzip_build.py` — 하프넥 고침(목이 가슴으로 처지지 않게 몸판 목선에 맞춰 낮게 서는 통) · 하프집업(11/27): 목이 접혀 어깨에 눕고
  안쪽 가장자리(지퍼, 연한 점선 zips)가 V로 내려와 같은 색 손잡이에서 만남. 반소매티 · 긴소매티 · 니트(+크롭) · 맨투맨, 핏별.
- 슬림 몸통 선(11/27, sleeves_b.py `SLIM_STYLES` · `tee_profile`): 여성 폴로 도식을 보고 두 가지를 만들어 종류별로 골랐다.
  - 1번(베스트): 어깨 끝에서 거의 곧게 떨어지다 가슴 아래에서 휘어 허리(어깨~밑단 64%)에서 가장 좁고,
    밑단은 어깨 폭의 1.05. 기장 그대로.
  - 2번(나머지 상의 — 반소매티 · 크롭 포함, 반팔 소매는 0.66배로 가늘게. 슬리브리스는 밑단 0.98 · 기장 그대로 + 진동 밑 모서리 둥글게 ARM_ROUND): 어깨 끝부터 비스듬히 들어가 허리(56%)에서 가장 좁고, 밑단은 어깨보다 좁게(0.95). 기장 10% 줄임.
  - 반소매티(`slim_tee`): 레귤러를 가로로만 줄이고, 몸통 옆선은 어깨 끝(소매 구분선 위 끝)에서 시작해 구분선을 따라 겨드랑이 아래로
    이어지는 한 곡선. 소매는 그 선 바깥에 붙고 각도 그대로 가늘게("처음은 어깨선, 님은 가슴에서 시작").
  - 긴소매 · 소매 없는 옷(`slim_waist`): 겨드랑이 위는 소매에 가려 있어, 같은 높이에 허리가 오게 겨드랑이부터 잰다(허리 = 겨드랑이 폭의 1-d).
  - 팔은 그대로. 크롭은 긴 옷 길이로 잰 같은 선을 짧게 자른 것(기장 줄임 없음). 아우터 슬림은 예전대로 곧게.
- `dresses.py` — 원피스·점프수트 시안: 미니·미디·점프수트는 상의 그림(목 모양·소매·핏)을 줄여 치마/바지와 잇는다.
  롱원피스는 지금 그림을 살려(long_fixed) 일자 소매선 → 둥근 진동선, 긴팔은 팔을 살짝 벌림, 엉덩이 옆 꺾임 폄.
  미니 치마 주름은 윗부분만, 미디·롱 주름은 2줄 안(결정 전). 아직 앱 그림에는 안 넣음.
- `geo.py` — path 글자 ↔ 도형.
- `preview.py` — 앱(KindIcon.tsx)과 같은 순서로 SVG를 그리는 확인용 도구.
- `review.py`, `fits_review.py` — 전/후, 핏별 확인 표.
- `log.json` — 종류마다 쓴 배율(g), v12 팔과 겹친 정도, 바꾼 그림 목록.

## 규칙

- 팔: 11/16 v12와 같은 코트 팔. 어깨 끝에서 곧게, 폭은 코트 소매의 1.35배, 팔꿈치 0.45만 들어감.
  시안 그림은 종류 배율(place)을 씌운 v12 좌표에서 바꾸고 다시 시안 좌표로 되돌린다. 종류마다 v12 팔과 가장 잘 겹치는 배율 g를 고른다.
- 몸판·목·기장은 그대로. 몸판 선(허리 끈·밑단·크롭 선)은 새 옆선까지 늘리고 소매로 나가지 않게 자른다.
  소매 위 선(시보리·누빔)과 짜임 결은 새 팔로 옮긴다. 결은 간격을 유지하고 새 팔 밖으로 나가는 줄은 뺀다.
- 꽈배기 결은 목·어깨 쪽 위까지 반복해 올린다.
- 오프숄더·원숄더: 어깨선을 새로 그리지 않고 목 밴드 아래에서 팔이 곧게 내려온다.
- 카라: 셔츠 카라(목 뒤 밴드 + 날개 2개)를 기준으로, 날개 사이에 V 틈. 빅카라 = 큰 셔츠 카라, 스탠드 = 한 줄 밴드,
  니트 셔츠 카라 = 셔츠 카라를 니트 목둘레에 맞춤.
- 핏(11/20 원칙): 오버사이즈는 그림을 키우지 않고 천이 남게(드롭숄더, 몸판·소매 길게, 소매가 부풀었다 끝에서 모임, 선 추가 없이 윤곽만).
  슬림은 어깨 폭은 거의 그대로, 허리가 들어가고 밑단에서 다시 조금 나오며 소매가 조금 가늘다(11/22 "가로폭이 너무 좁다"로 고침).
  오버사이즈 치수는 11/20 니트 초안(FULL-JOIN-evals/design/fit-drafts)에 맞췄다. 11/22 후드 드로잉 참고로
  어깨에서 팔로 꺾이는 곳을 살짝 각지게(드롭숄더 재봉선 자리), 소매 구분선이 끝난 아래로 밑단 시보리가 안으로 들어가
  소매 끝과 떨어지게 했다. 주름 선은 넣지 않는다.
  11/22 밤("부푼 풍선 소매는 이상" → 사이즈표 그림의 후드집업·카디건 참고): 소매는 몸에 붙지 않고 바깥으로 비스듬히 내려가는
  넓은 통 + 끝은 시보리로 살짝 모임, 겨드랑이 아래 몸판 옆선은 곧게(박스), 시보리 밑단이 있는 옷(니트·맨투맨·후드·카디건 등)은
  밑단이 조금 안으로.
  모든 상의 모양에 적용(소매 짧은 옷·민소매·베스트는 몸판만).

- 하프넥·터틀넥(11/23): 목 밴드 안의 세로 골지 줄은 넣지 않는다(반소매티·긴소매티·니트). 니트는 몸판 목선이 티셔츠보다
  높아서 밴드를 3.1 올려 밴드 아래 끝이 목선보다 1.1 아래(긴소매티와 같음)가 되게 한다(터틀넥도 같이).
  밴드를 올린 자리에 짜임 결이 비지 않게, 니트 결(골지·꽈배기)은 기본 그림의 목 시보리(plain) 자리까지 채운다
  (기본 그림에선 plain이 결 위에 칠해져 안 보임). 다른 니트 목 모양은 픽셀 비교로 그대로인 것을 확인했다.

## 11/23 오전
- 니트 하프넥·터틀넥: 목 골지 줄을 `ribs` 층에 따로 둔다. 앱(wardrobeLook.lookFor)은 짜임이 골지('kn|골지|…')일 때만 details에 더해 그린다.
  골지 줄은 위쪽 가로줄 바로 아래부터 밴드 아래 끝까지.
- 터틀넥(반소매티·긴소매티·니트): 밴드 가운데 가로선(목둘레)을 뺀다. 위쪽 접힌 선은 그대로.
- 퍼자켓 후드: 짧은 털은 원래대로(털 점 채우기 되돌림), 긴 털·뽀글은 후드 안쪽이 보이게 후드 면을 뚫는다.
- 반소매티(A안으로 정함): 긴소매티와 같은 팔을 그려 위쪽만 남긴 짧은 소매(SHORT 값) + 소매단 선 + 몸판 밑단 선.
  앱 기본 그림(v12 반소매티셔츠)도 바꾼다: fits_b.json의 '기본' → gen_add_item이 icons_v13에 넣고 gen_ts.py로 kindIcons.ts.
- 퍼자켓 스탠드: 목을 감싸는 털 칼라를 몸판과 한 덩어리로(목 밑 선 없음, 앞 맨 위만 살짝 파임). 짧은 털은 위가 평평한 네모.
