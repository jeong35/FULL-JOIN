# 옷 종류 그림 (48종)

옷장 타일 · 옷 추가 ①② · 저장 후 결과 화면에 쓰는 옷 그림이다. 미리보기는 `옷종류그림_전체.png`.

- 앱 코드: `mobile/src/components/KindIcon.tsx` (그리는 부품), `mobile/src/data/kindIcons.ts` (그림 데이터, 자동 생성)
- 64×64 칸, 앞모습(신발은 옆모습). 옷장에서는 옷 색으로 칠하고, 색을 모를 땐(옷 추가 ①) 연보라 `#CDB8F4`.
- 멀티는 4색 줄무늬, 기타·색 모름은 옅은 회보라 `#D9D2E6`.
- 핏에 따라 모양이 바뀌는 종류: 데님팬츠·슬랙스·코튼팬츠(스키니·일자·와이드·부츠컷), 미니·미디·롱스커트(A라인·H라인·플레어).
- 직접 그린 그림이라 저작권 걱정 없이 고쳐 써도 된다.

## v3 (11/7) — 곡선으로 다시 그림

은재님이 보낸 패션 일러스트의 '선'을 참고했다(그림을 베끼지 않고 선 쓰는 방식만).

- 어깨·소매·옆선·밑단을 곡선으로(점을 부드럽게 잇는 베지어). 꺾여야 하는 곳만 각지게.
- 진한 테두리 `rgba(43,34,56,0.9)` 굵기 1.35, 끝은 둥글게.
- 안쪽 선·옷 안쪽·그림자 색은 옷 색에서 뽑는다(같은 색 계열). 밝은 옷은 진하게, 어두운 옷(밝기 0.3 미만)은 밝게 섞고,
  어두운 옷의 라펠·칼라 테두리도 밝은 같은 색으로 그린다. 회보라·반투명 흰 선을 쓰면 탁해 보여서 바꿨다(`KindIcon.tsx`의 `tonesFor`).
- 칼라·라펠·주머니 덮개는 따로 겹치는 면(tops), 목 안·후드 안은 어둡게(inner).
- 빛이 왼쪽 위에서 온다고 보고 오른쪽 옆구리에 옅은 그림자(shade). 경계가 딱 끊기지 않게 왼쪽→오른쪽으로 옅게 짙어진다.
- 꺾이는 모서리(소매 끝·밑단·주머니)는 0.9만큼 둥글게 깎아 끝이 뾰족하지 않다. 잔주름 같은 군더더기 선은 뺐다.
- 그림자와 솔기 선은 옷 모양 안으로 잘라서(clipPath) 밖으로 삐져나오지 않는다.
- 부츠컷은 '무릎에서 좁아졌다 밑단에서 퍼지는' 모양을 그대로 살렸다.

## 그림 고치는 법

1. `gen_icons_v3.py`에서 해당 종류의 `add("종류", ...)` 줄을 고친다. 점은 `(x, y)`는 부드럽게, `(x, y, "c")`는 꺾이게 이어진다.
   왼쪽·오른쪽이 같은 옷은 오른쪽 반(가운데 위 → 가운데 아래)만 주면 `sym()`이 거울로 붙인다.
2. 다시 만들기 (FULL-JOIN 폴더에서):
   ```
   python3 design/kind-icons/gen_icons_v3.py /tmp/icons.json
   python3 design/kind-icons/gen_ts.py /tmp/icons.json mobile/src/data/kindIcons.ts
   ```
3. 종류 목록(`mobile/src/data/catalog.ts`)이 바뀌면 `gen_ts.py`의 `order`도 같이 바꾼다.

`gen_icons.py`·`gen_icons_v2.py`는 예전(직선) 버전이라 지워도 된다.
