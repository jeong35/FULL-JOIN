# 스파이크 — 구조화 출력

> 핵심 기능이 얼마나 잘 되는지(태깅 정확도, 옷장 대조 일치율)는 스파이크가 아니라 **evals**에서 잰다 → `evals/README.md`

- **가정**: OpenAI API(Structured Outputs strict 모드)가 사진을 보고 출력 스키마(`src/fulljoin/schemas/style_image.schema.json`) 형식(부위·종류·색·핏, 칩 목록 값만)으로 결과를 돌려준다.
- **방법**: 피드에 올릴 사진 3장(쇼핑몰 1장, 인플루언서·연예인 1장, 직접 찍은 사진 1장)을 파이썬 스크립트로 호출하고 스키마로 검증
- **성공 조건**: 3장 모두 파싱 오류 없음, 칩 목록 밖의 값 없음
- **안 되면**: 형식 검증 후 재요청, 칩 목록 단순화, 다른 모델 검토
- **판단·재도전 조건**: 3장 중 하나라도 실패하면 칩 목록을 줄여서 1번 다시 해 본다. 그래도 실패하면 다른 모델로 같은 3장을 비교한다.
- **결과**: _실험 후 작성_
